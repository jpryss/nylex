#
# lexdef-en.txt - the records of nylex's English system file
# (nylex-en.vmf): menus, help pages, forms, printers, messages,
# dictionaries and output formats for the document index and an address
# register.  The English counterpart of lexdef.txt; tools/mklexvmf.py
# makes the .VMF of it.
#
# "== KEY [kind]" starts a record (see tools/mklexvmf.py): plain text,
# "fixed" (OFFSET:text lines), "form" (a program that draws a form) or
# "page" (a help page).  Text is ASCII: the **MONT below has English
# hyphenation, so nylex shows [ \ ] { | } as they are rather than as
# Swedish letters.  Its keys are those of the German/Scandinavian table
# of the manual (table 5.1), not of its English figure 5.1, so that
# brackets can be typed: < and > start and end a key, and in programs
# $ is ESC, ' Ctrl, ; Return, ( and : the start and end keys, @ the
# next character as it is, ! a pause until Return.
#
# Menus: the first line is the heading ("." the program's name); then
#   column 0      the menu switch option (see nylex(1))
#   columns 1-10  a record for it
#   column 11     the character that chooses the line
#   then          the text
#

== *HELP1 page
                     The cursor and the Ctrl keys
          (Ctrl is held down while the other key is pressed)

  Ctrl U   Ctrl J    a line up, a line down     (the arrows do the same)
  Ctrl H   Ctrl R    a character left, right
  Ctrl F   Ctrl B    next word, previous word
  Ctrl G             the end of the line
  Ctrl L   Ctrl T    a screen forward, back
  Ctrl O   Ctrl S    the start, the end of the document
  Ctrl I   (Tab)     the next tab stop          ESC Tab  the previous
  Return             the next line, first column
  Ctrl A             a blank line in
  Ctrl X             the line out               ESC - X  back again
  Ctrl D   Ctrl P    the character out (P: the paragraph follows)
  Ctrl E   Ctrl N    a space in (N: the paragraph follows)
  Ctrl V             the rest of the line out
  Ctrl W             the word out               ESC - W  back again
  Rubout             the character on the left out  ESC - D  back
  Ctrl Y             the character above is copied
  Ctrl K             the word changes case
  Ctrl C             stops a program

                                       Return to go back
== *HELP2 page
                             ESC commands
          (ESC is pressed and let go, then the next key)

  ESC E     save and finish           ESC Z     finish without saving
  ESC V     save and start again      ESC Q X   save, stay where you are
  ESC I     insert mode on            ESC - I   insert mode off
  ESC J     justify the paragraph     ESC Ctrl J  split the paragraph
  ESC G     find (Return: whatever the case of the letters)
  ESC - G   find backwards            ESC X     repeat
  ESC S n   keystore n (0-9) becomes the text typed
  ESC n     keystore n is typed       ESC P     page break
  ESC K     the date yymmdd           ESC Y     the date in full
  ESC Q N   the time                  ESC +     the calculator
  ESC A n   attribute n on            ESC B n   attribute n off
  ESC @     centre the text           ESC #     right-justify the text
  ESC \     typing downwards          ESC - \   across again
  ESC M n   ruler n in                ESC U n   use ruler n
  ESC W n   the line becomes ruler n  ESC L     status line

                                       Return to go back
== *HELP3 page
                                Rulers

  A ruler holds for the text under it, down to the next ruler.

  F...........M   paragraphs with a ragged right margin, from F to M
  F...L.......M   a tab stop between F and M: an indent
  J...........M   paragraphs with a straight right margin
  C...........M   the text is centred between C and M (with Tab)
  ....L.....L..   tab stops
  ..R.......L..   the text is right-justified on R (with Tab)
  ..T..........   a stop not used in insert mode
  ..##,###.##..   a number field: Tab, the number, Tab - lined up; calculator
  .......H.....   hyphenation to the left of H

  ESC M n    ruler n (1-9) is put in at the cursor
  ESC W n    the line the cursor is on is kept as ruler n
  ESC U n    ruler n is used without being put in

  Rulers 1-5 of each document type are in the record *.LTR and so on.

                                       Return to go back
== *HELP4 page
                             Cut and paste

  ESC (        mark the start
  ESC ) L      copy up to the cursor (the text is left)
  ESC ) B      copy and blank
  ESC ) S      cut (the text to the right moves in)
  ESC ) x L    the same to buffer x (T-Z), ESC ) n L to keystore n
  ESC . L  ESC . B  ESC . S   the same for sentences

  ESC * I      paste, the lines below move down
  ESC * O      paste over what is there
  ESC * E      paste, the text to the right moves
  ESC * D      empty the buffer

  Both corners in column 1: whole lines.

                                       Return to go back

== *HELP6 page
                      Records, forms and programs

  <KEY>       performs the record KEY (its text is typed as keys)
  ESC > R     read the record whose key is after the < on the line
  ESC > P     save the record        ESC > K  delete the record
  ESC N       the next key           ESC - N  the previous key
  ESC S P     protect mode (forms): only the fields can be typed in
  ESC U P     protect mode off

  On a form: Ctrl L to the last field, then ESC > P saves.

  (In programs the end key > is written :, the start key < as (.)

  In programs: $ ESC   ' Ctrl   ; Return   @ the next character as it is
               ! a pause until Return   "..." a comment

                                       Return to go back
== *HELP7 page
                               Spelling
       (S in the main menu; the program lexspell, see man lexspell)

  C  Check a document: each unknown word is shown in its line with
     suggestions.  A number takes the suggestion, R types a correction,
     Return or A accepts the word for the rest of the document, L puts
     it in your own word list, F finishes (the corrections are saved),
     Q abandons.  The old document is kept as name.bak.
  A  The same, with an extra word list (its name is asked for).
  U  The unknown words of a document are written into another.
  S  Spell words, one at a time.  P  Words by pattern: ? a letter,
  L  The dictionary from a word.       * letters (crosswords: c??s*)
  W F R Y  Words and files of words into and out of the common list.

  The dictionary is British English; en-US at character 33 of the
  records *=SPLDEF... makes it American (sv: Swedish).
  The word lists: $HOME/user.def (your own), $HOME/common.def (common).

                                       Return to go back
