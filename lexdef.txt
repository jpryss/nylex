#
# lexdef.txt - the records of nylex's system file (nylex.vmf): menus,
# help pages, forms, printers, messages, dictionaries and output formats
# for the document index and an address register.  Written for nylex
# (the D-NIX Amiga port's LEX lookalike); tools/mklexvmf.py makes the
# .VMF of it.  None of it is taken from LEX's own system file; the
# layouts of the system records are those LEX's technical manual gives,
# so that LEX-68's lex9a1.vmf can be used as well (nylex -f lex9a1.vmf).
#
# "== KEY [kind]" starts a record (see tools/mklexvmf.py): plain text,
# "fixed" (OFFSET:text lines), "form" (a program that draws a form) or
# "page" (a help page).  Text is 7-bit Swedish: [ \ ] { | } are
# Ä Ö Å ä ö å.  In programs the Swedish **MONT's visible equivalents
# are used: $ ESC, ' Ctrl, ; Return, ( and : the start and end keys,
# @ the next character as it is, ! a pause until Return.
#
# Menus: the first line is the heading ("." the program's name); then
#   column 0      the menu switch option (C E V P Q A K R M X S L U F
#                 Z 1 2 T W 0 3 4 ...; see nylex(1))
#   columns 1-10  a record for it
#   column 11     the character that chooses the line
#   then          the text
#
